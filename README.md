# SantaList Security Audit Report

Security audit of Cyfrin First Flight – SantaList, focused on identifying smart contract vulnerabilities, logic flaws, and security risks in the protocol.

## Overview

This repository contains my independent security review of the SantaList smart contract from Cyfrin's First Flight challenges.

The goal of the audit was to analyze the contract from an attacker's perspective, identify vulnerabilities, and document reproducible Proofs of Concept (PoCs) for the discovered issues.
